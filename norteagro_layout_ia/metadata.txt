about=Norte Agro Projetos plugin that builds the Land Use map and the Environmental Liabilities map of a rural property in Brazil (CAR) from templates: it reads the CAR receipt and the property registry PDF locally, uses the area table produced by the "Norte Agro - Uso do Solo" plugin and generates the layout with legend, area tables, north arrow, scale, municipality location and the technical manager block (filled in Settings). Each map has its own layers, CRS and extent; variable texts use project variables (@na_*). Optional OCR for scanned documents uses a separate Python environment that the user installs (support folder). The user interface is in Brazilian Portuguese. | Plugin da Norte Agro Projetos que gera a Planta de Uso do Solo e a Planta de Passivos do imóvel a partir de modelos, lendo o recibo do CAR, a matrícula e o Quadro de Áreas do plugin "Norte Agro - Uso do Solo". O responsável técnico é preenchido em Configurações.

    0.32.5 - Pronto para o repositório oficial do QGIS (licença GPL, descrição em inglês). Vídeos da Ajuda pela internet: assim que publicados, o QGIS avisa e baixa em segundo plano (ao abrir e a cada 2 horas), sem precisar de versão nova do plugin. Sem dados pessoais de fábrica.
    0.32.4 - Fase de teste: os plugins não pedem mais a chave de acesso (repositório público). Vídeos da Ajuda chegam junto com as atualizações: ficam numa pasta do QGIS fora do plugin (atualizar não apaga mais nenhum vídeo) e, ao abrir o QGIS, o plugin baixa em segundo plano só os vídeos que faltam e tira os que saíram. Cartão "Baixando"/"Baixar agora" na Ajuda. Saiu o botão "Gerar ZIP com os vídeos".
    0.32.3 - Atualizações pelo repositório da Norte Agro: os plugins cadastram sozinhos o repositório no QGIS e, por ser privado, pedem a chave de leitura uma vez (aviso "Configurar acesso"). A cada abertura do QGIS a chave é conferida em segundo plano e, se tiver vencido ou sido cancelada, o aviso volta para colar a chave nova.
    0.32.2 - Janelas no tamanho certo em qualquer tela: abrem no monitor onde está o QGIS (com dois monitores de escalas diferentes, ex.: notebook 150 por cento + monitor 100 por cento, a janela não encolhe mais para 2/3), nunca passam de 94 por cento x 90 por cento da tela (antes o Windows distorcia a janela pedida maior que a tela, ex.: 1180 x 820 num monitor 1366 x 768), ficam centralizadas e, quando o conteúdo não cabe, ganham barra de rolagem em vez de espremer ou cortar campos e botões. Tamanhos lembrados das versões antigas são descartados. Senha nos vídeos da Ajuda: salvar, trocar, editar e apagar vídeos pedem a senha (uma vez por janela da Ajuda; senha errada não deixa). "Mudar a senha..." só funciona com o arquivo IDENTIFICADOR (.naid). A senha vai junto no "Gerar ZIP com os vídeos".
    0.32.1 - Vídeos da Ajuda: botão "Salvar vídeo no plugin..." grava o vídeo numa pasta própria do assunto dentro do plugin (videos\\<nome do assunto>) e mostra onde ficou; "Apagar" apaga o arquivo dessa pasta; "Mostrar na pasta do plugin" abre o Explorador no arquivo.
    0.32.0 - Vídeos dentro da Ajuda (?): ao lado do texto de cada assunto fica o lugar do vídeo dele - anexe o arquivo gravado (sem limite de tamanho), assista, troque ou remova; "+ Mais um vídeo" para vídeos fora dos lugares; "Gerar ZIP com os vídeos". Saíram o gravador e o botão ▶ Vídeos. Ajuda completa em 12 assuntos (etapas, personalizar cada mapa, rodapé, buscar imagem, configurações e configurações avançadas).
