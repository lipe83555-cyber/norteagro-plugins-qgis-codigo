# Norte Agro - plugins QGIS (código)

Código-fonte dos plugins QGIS da **Norte Agro Projetos**, publicados no repositório oficial do QGIS:

- **Norte Agro - Uso do Solo** (`norteagro_uso_solo`): land use layers, area table (Excel) and KML for the Brazilian
  Rural Environmental Registry (CAR/SICAR). / Camadas de uso do solo, Quadro de Áreas e KML para o CAR.
- **Norte Agro - Layout de plantas** (`norteagro_layout_ia`): land use and environmental liabilities map layouts.
  / Plantas de Uso do Solo e de Passivos.

Instalar: QGIS > Complementos > Gerenciar e instalar complementos > aba Todos > procure **Norte Agro** > Instalar.
A interface é em português. Os vídeos da Ajuda são baixados de https://github.com/lipe83555-cyber/norteagro-plugins-qgis quando há internet.

Este repositório é igual ao conteúdo dos ZIPs enviados ao plugins.qgis.org (gerado por `publicar_repositorio.py`).
